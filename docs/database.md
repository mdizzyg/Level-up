# LEVEL UP — Database

## 1. СУБД

PostgreSQL

## 2. Основные сущности

Планируемые таблицы:

- users
- weekly_goals
- categories
- tasks
- deals
- capital_transactions
- capital_history

## 3. Назначение таблиц

### users

Хранит данные пользователя.

### weekly_goals

Хранит недельные финансовые цели.

### categories

Хранит категории направлений заработка.

Примеры:

- Sport
- Gaming
- Investments
- Other

### tasks

Хранит действия и задачи пользователя.

### deals

Хранит сделки:

- покупка;
- продажа;
- расходы;
- прибыль;
- ROI;
- статус.

### capital_transactions

Хранит движения капитала.

### capital_history

Хранит историю изменения капитала.

## 4. Следующий этап

Необходимо определить:

- Primary Keys;
- Foreign Keys;
- типы данных;
- связи между таблицами;
- ограничения;
- статусы;
- ER-диаграмму.
